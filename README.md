# Verificateur-de-mot-de-passe
## Description
Ce projet est un programme simple développé en Python qui permet de vérifier si un mot de passe respecte certains critères de sécurité.

Le programme demande à l'utilisateur de saisir un mot de passe puis effectue plusieurs vérifications avant de le valider.

## Fonctionnalités

- Vérification de la longueur minimale du mot de passe.
- Vérification de la présence d'au moins un caractère spécial.
- Affichage d'un message d'erreur si le mot de passe est trop court.
- Validation du mot de passe lorsqu'il respecte les critères définis.

## Technologies utilisées

- Python 3

## Concepts utilisés

- Boucles `while`
- Boucles `for`
- Conditions `if/else`
- Variables
- Listes
- Validation de données

## Objectif pédagogique

Ce projet a été réalisé dans le cadre de mon apprentissage de Python afin de comprendre la gestion des chaînes de caractères, les structures conditionnelles et les boucles.
